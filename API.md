# LearnHub API Documentation

## Базовая информация

- **Base URL:** `http://localhost:3000`
- **Формат данных:** JSON
- **Авторизация:** Bearer token в заголовке Authorization

---

## Эндпоинты

### Проверка здоровья

**GET /health**

Проверяет работоспособность сервера.

Ответ (200 OK):
```json
{
  "status": "ok",
  "timestamp": "2025-01-20T12:00:00.000Z",
  "uptime": 3600.5
}
```

---

### Аутентификация

#### Регистрация

**POST /api/auth/register**

Создаёт нового пользователя.

Тело запроса:
```json
{
  "email": "user@example.com",
  "password": "123456",
  "name": "Иван Иванов",
  "birthDate": "1990-01-01"
}
```

Ответ (200 OK):
```json
{
  "success": true,
  "message": "Регистрация успешна",
  "user": {
    "id": 1,
    "name": "Иван Иванов"
  }
}
```

Ошибки:
- 400 — Неверный формат данных (некорректный email, короткий пароль, неверная дата рождения)
- 400 — Пользователь с таким email уже существует
- 500 — Внутренняя ошибка сервера

#### Вход

**POST /api/auth/login**

Авторизует пользователя и возвращает токен.

Тело запроса:
```json
{
  "email": "user@example.com",
  "password": "123456"
}
```

Ответ (200 OK):
```json
{
  "success": true,
  "message": "Вход выполнен",
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "user": {
    "id": 1,
    "name": "Иван Иванов"
  }
}
```

Ошибки:
- 400 — Неверный формат данных (некорректный email, короткий пароль)
- 401 — Неверный email или пароль
- 500 — Внутренняя ошибка сервера

### Курсы

#### Получить список курсов

**GET /api/courses**

Возвращает список всех курсов.

Ответ (200 OK):
```json
{
  "success": true,
  "courses": [
    {
      "id": 1,
      "title": "Основы программирования",
      "description": "Описание курса 1",
      "pages": [
        {
          "type": "text",
          "title": "Введение в программирование",
          "content": "Программирование — это процесс создания компьютерных программ..."
        }
      ]
    }
  ]
}
```

#### Получить конкретный курс по ID

**GET /api/courses/:id**

Возвращает информацию о конкретном курсе по его ID.

Параметры:
- `id` (число) — ID курса

Ответ (200 OK):
```json
{
  "id": 1,
  "title": "Основы программирования",
  "description": "Описание курса 1",
  "pages": [
    {
      "type": "text",
      "title": "Введение в программирование",
      "content": "Программирование — это процесс создания компьютерных программ..."
    }
  ]
}
```

Ошибки:
- 404 — Курс не найден

### Профиль пользователя

#### Получить профиль пользователя

**GET /api/profile**

Возвращает информацию о профиле авторизованного пользователя.

Заголовки:
```
Authorization: Bearer <token>
```

Ответ (200 OK):
```json
{
  "name": "Иван Иванов",
  "email": "user@example.com",
  "birthDate": "1990-01-01",
  "avatar": "https://via.placeholder.com/100",
  "courses": [...],
  "bio": "Люблю учиться и развиваться.",
  "createdAt": "2025-01-20T12:00:00.000Z"
}
```

Ошибки:
- 401 — Не авторизован (токен отсутствует или недействителен)
- 404 — Пользователь не найден
- 500 — Внутренняя ошибка сервера

---

## Коды ошибок

| Код | Описание |
|-----|----------|
| 200 | Успешный запрос |
| 400 | Неверный запрос (ошибка валидации) |
| 401 | Не авторизован |
| 404 | Ресурс не найден |
| 500 | Внутренняя ошибка сервера |
